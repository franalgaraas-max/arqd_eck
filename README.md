# Arqd.eck — Sitio Oficial (GitHub Pages)

Repositorio listo para publicar en `https://franalgaraas-max.github.io/arqdeck/`.

## Cómo actualizar tu web en GitHub
1. Subí el archivo `index.html` a la raíz de tu repositorio `arqdeck` en GitHub (`Add file -> Upload files`).
2. Confirmá con el botón verde **Commit changes**.
3. En **Settings -> Pages**, asegurate de que la rama `main` (root `/`) esté seleccionada.
